Our solution

EDUKI: A platform that adapts to each neuroprofile with AI technology

1. Cognitive Detection

Cognitive detection chatbot

It's not a medical diagnosis, but it identifies characteristics using scientifically validated scales.

  • ✓ Questions based on ASRS, AQ-10, Sensory Profile
  • ✓ Identification of ADHD, Autism and Dyslexia patterns
  • ✓ Redirection to adapted experience
2. Visual Adaptation

Adaptive interface

The visual experience changes completely according to the detected profile.

  • ✓ Optimized typography (OpenDyslexic for dyslexia)
  • ✓ Personalized color palettes and contrasts
  • ✓ Adjusted stimulus level
  • ✓ Adapted navigation structure
