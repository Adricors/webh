Nuestra solución

EDUKI: Una plataforma que se adapta a cada neuroperfil con tecnología de IA

1. Detección Cognitiva

Chatbot de detección cognitiva

No es diagnóstico médico, pero identifica características mediante escalas validadas científicamente.

  • ✓ Preguntas basadas en ASRS, AQ-10, Sensory Profile
  • ✓ Identificación de patrones de TDAH, Autismo y Dislexia
  • ✓ Redirección a experiencia adaptada
2. Adaptación Visual

Interfaz adaptativa

La experiencia visual cambia completamente según el perfil detectado.

  • ✓ Tipografías optimizadas (OpenDyslexic para dislexia)
  • ✓ Paletas de colores y contrastes personalizados
  • ✓ Nivel de estímulos ajustado
  • ✓ Estructura de navegación adaptada
3. Contenido Adaptativo

Demo de álgebra básica

El mismo contenido matemático, presentado de manera completamente diferente

💙 Autismo

Interfaz limpia

Problema:

2x + 5 = 13

Solución:

x = 4

  • ✓ Tipografía monoespaciada
  • ✓ Sin estímulos visuales
  • ✓ Estructura predecible
💛 Dislexia

Lectura facilitada

P r o b l e m a :

2 x + 5 = 1 3

R e s p u e s t a :

x = 4

  • ✓ Espaciado aumentado
  • ✓ Alto contraste (beige)
  • ✓ Separación clara
🧡 TDAH

Paso a paso

Paso 2 de 3 ⭐ +10 pts

📝 Resta 5 de ambos lados:

2x + 5 - 5 = 13 - 5

✅ ¡Excelente!

2x = 8

  • ✓ Micro-pasos con recompensas
  • ✓ Retroalimentación inmediata
  • ✓ Barra de progreso
